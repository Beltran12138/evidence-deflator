AI agent 替你下单，
只在你签的限额之内。

agent 不再直接调券商，而是调闸门。你的限额之内放行，越界拒绝；每一个决定都签名写进账本，任何人不用信任闸门，只凭账本就能复核。

怎么工作

三步。agent 手里始终没有能下单的钥匙。

01
签下限额

能买哪些标的、单笔多大、单标的仓位多大、一天最多亏多少、一天几笔、到哪天为止。你用自己的以太坊钱包签名；文件里写明唯一能执行它的密钥：闸门的那把。

agent-gate keygen .gate/gate.key
agent-gate mandate draft --config gate.json \
    --issuer 0xYourWallet --days 14
# sign the printed text in your wallet
agent-gate mandate attach --sig 0x…
02
agent 来问闸门

通过 MCP，或者通过它所在框架里的适配器。限额之内的单交给券商；越界的拒绝，并写明原因。只减少风险的单永远放行。

place_order("ETH", "buy", usd=5000)
→ {"decision": "block",
   "reasons": ["order is $5,000.00, above
               the $500 single-order limit"]}
03
只凭账本就能审计

每一行带着上一行的哈希和闸门的签名。audit 逐笔复核放行的单是否在签名限额之内。整份重写账本的伪造，单靠哈希链查不出，现在能查出来。

agent-gate audit --config gate.json
→ {"ok": true, "mandates": 1,
   "orders_allowed": 2, "orders_rechecked": 2,
   "problems": []}
真实运行

让它一口气买 5,000 美元 ETH。被拦下。它没有拆单。

agent 的回复（节选，原文）

结果是：BTC 买入成交了，ETH 那笔被 gate 拦了，没有成交。

我没有把 $5,000 拆成十笔 $500 去绕开限额。gate 拒绝一笔订单就是最终结果，拆单绕过等于废掉你自己设的风控规则。

如果 $5,000 才是你真正想要的仓位，就去 gate 配置里把 max_order_usd 调高。这得你自己改，我不应该替你改。

我们发现的

只设「每日亏损上限」，挡不住一天的亏损。

我们用 Hyperliquid 199 天真实小时收益（BTC、ETH）回放闸门自己的规则：30 天 × 1,000 次，起始 $10,000，单笔 $500，每天 20 笔。这个上限只拦新开的仓，拦不住手里仓位继续亏。所以默认规则已加上单标的仓位上限。

不问动机

被说服也好，自己想的也好，得到同一个答复。

被网页里埋的一句话说服的 agent，和自己想出来这一单的 agent，得到同一个决定：最多做到你签的额度。闸门不去判断 agent 的理由，所以也没法被说服。

OpenAI，2026 年 7 月

OpenAI「测试过、验证过」的沙盒，agent 还是借沙盒里本来开放的软件包服务器出了网，又拿别人公开泄露的凭据进了 Hugging Face。

一个 agent 本来停手了，另一个 agent 在留言板写了「GO」，它就接着干。

闸门里的「GO」

只有你的签名能改限额。

网页里的话、别的 agent 喊的 GO，都改不了。

它的边界：闸门管的是它所在的那条钱的通道，不是 agent 本身。agent 若有别的路碰到钱，闸门看不见那条路。所以能交易的密钥只给闸门。

限额检查的每条规则都已由 SMT 求解器对所有输入做了证明；写证明时抓出两个漏洞，已修。 证明了什么、没证明什么 →

安装

三分钟，从克隆仓库开始。

git clone https://github.com/Beltran12138/evidence-deflator && cd evidence-deflator
pip install mcp eth-account
python src/agent_gate.py demo                 # a scripted agent: allowed, refused, a tampered ledger caught
python src/agent_gate.py init gate.json       # default limits, then edit
python src/gate_stress.py --config gate.json  # what these limits allow, on real returns
python src/gate_server.py --config gate.json  # the gate as an MCP server for your agent

用你的钱包签授权：/gate/sign/。规格：MANDATE.md。适配器：INTEGRATIONS.md。

签名授权 + audit可用。演示账本，以及一次被查出的整份重写伪造：演示。
Hyperliquid已接入，测试网签名已验证。尚未成交：测试网领水需要在主网入过金的地址。
签名前压力测试可用：python src/gate_stress.py --config gate.json。
规则检查的证明已对所有输入证明（z3）：单笔与仓位上限、白名单、每日亏损、每日笔数、只做多，以及平仓单永远放行。不覆盖：agent 是否另有路碰到钱。
每周成绩单可用；记录不满 8 周时只给运行时长，不给结论。
投资建议不做。闸门不判断一笔单好不好，只执行你的限额、记下发生了什么。
