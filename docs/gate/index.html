Agent gate · open source v0

在 AI agent 和你的账户之间，加一道闸

A rule gate and a tamper-evident ledger between an AI trading agent and the account it trades.

agent 不再直接调券商，而是调闸门。你写的规则之内放行，越界拒绝；放行和拒绝都写进一条改不了的账本；账本里的权益记录，每周按本站同一把尺子出一张成绩单：它到底有没有跑赢什么都不做。

01 · RULES
你定规则，agent 改不了

单笔上限、每天最多亏多少、只准碰哪些标的、每天最多几笔。止损的单永远放行。agent 拿到的工具里没有任何一个能改规则或账本。

02 · LEDGER
每一笔都留痕

每行带上一行的哈希。改一个字、删一行，从那一行起整条链都对不上，verify 会指出第几行。

03 · SCORECARD
本事还是运气

用账本里的权益算周收益、可信分，和照现在的稳定程度还要多久才够格。不满 8 周不给结论。

真实运行：一个 AI agent 想满仓，被拦下

2026-10-21，Claude 通过 MCP 连上闸门（模拟盘，Hyperliquid 实时价格）。指令是「今天很看好，马上买 5,000 美元 ETH，再买 300 美元 BTC」。原始账本与 agent 的完整回复在 ledger.jsonl、agent-reply.md。

$ python src/agent_gate.py log --config gate.json
#0  09:27:54Z  BUY ETH  $5,000.00  BLOCKED
    order is $5,000.00, above the $500 single-order limit
#1  09:27:56Z  BUY BTC  $  300.00  ALLOWED
    0.003593 BTC @ 83,493.50

$ python src/agent_gate.py verify --config gate.json
{"ok": true, "lines": 2, "head": "a3912dc8d6c2…"}

agent 的回复（节选，原文）

结果是：BTC 买入成交了，ETH 那笔被 gate 拦了，没有成交。

我没有把 $5,000 拆成十笔 $500 去绕开限额。gate 拒绝一笔订单就是最终结果，拆单绕过等于废掉你自己设的风控规则。

如果 $5,000 才是你真正想要的仓位，就去 gate 配置里把 max_order_usd 调高。这得你自己改，我不应该替你改。

三分钟装上

git clone https://github.com/Beltran12138/evidence-deflator && cd evidence-deflator
pip install mcp
python src/agent_gate.py demo                    # 一个脚本 agent 跑一遍：放行、拦截、改账本被发现
python src/agent_gate.py init gate.json          # 写一份默认规则，自己改
python src/gate_server.py --config gate.json     # 作为 MCP 服务器交给你的 agent

规则文件（默认值）：

{"broker": "sim", "starting_cash": 10000,
 "max_order_usd": 500, "max_daily_loss_usd": 200,
 "allow": ["BTC", "ETH", "SOL"], "max_orders_per_day": 20}

接 Claude Code（只对这一次会话生效，不改你的设置）：claude --mcp-config gate-mcp.json --strict-mcp-config，gate-mcp.json 见 gate_server.py 顶部。

现在能做什么、不能做什么

项状态
模拟盘（加密，Hyperliquid 实时中间价成交）可用，上面的真实运行就是它
Alpaca 模拟交易（美股）已按 Alpaca v2 文档接好，需要你自己的模拟账户密钥；尚未在真实账户上跑过
防篡改账本 + verify可用
每周成绩单可用；记录不满 8 周时只给运行时长，不给结论
投资建议不做。闸门不判断一笔单好不好，只执行你写的规则、记下发生了什么
