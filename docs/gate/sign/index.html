Agent gate · Trading Mandate v0

用你自己的钱包，给 AI agent 签一份交易授权

两步都在你的钱包里签名，这个页面不保存、也不上传任何东西。第一步签的是授权文件：哪些标的、单笔多大、一天最多亏多少、到哪天为止。第二步是在 Hyperliquid 上把闸门的密钥批准为你账户的 API 钱包：它能替你下单；用同一个名字批准另一把密钥，旧的就失效。（它能否提币，Hyperliquid 文档没有明说，我们还没实测。）agent 手里没有任何能下单的密钥。

规格：MANDATE.md。

1 · 签授权文件

不用会 AI，也不用懂代码：用一句话写下你的规则，闸门把它变成授权。比如“只做苹果和 SPY，单笔不超过 500 美元，一天最多亏 200 美元，每只股票最多拿 2000 美元，两周有效”。这一步不用任何 AI，同一句话永远得到同一套规则；看不懂的地方会直接告诉你，不会替你猜。

不问“你能承受多大风险”，直接给你看具体的单子，你只要选放行还是拦下。每条规则大约问三四次，最后都会标出来自你的哪几个回答。账户和闸门密钥地址用上面填的。

也可以直接对你的 agent 说规则，agent 用闸门的 propose_mandate 工具起草；或者在终端运行 agent-gate mandate draft --config gate.json --issuer 你的地址。拿到的整段文字（从 “Trading mandate v0” 开始）都贴在下面。签名前请逐项看清楚范围和到期时间。

由代码根据上面的授权算出，不是 AI 猜的。哪一条和你想的不一样，就说明授权写错了：先改，再签。Anthropic 的 agent 交易实验发现，损失主要来自 agent 没理解它代表的人，而不是议价，并建议先给人看几个样例决定再放手（Project Swap）。

    2 · 在 Hyperliquid 上批准闸门的密钥

    闸门密钥的地址就是授权文件里的 agent。批准是 Hyperliquid 自己的 approveAgent 动作，由你的主钱包签名；最长 180 天有效，用同一个名字再批准一次即替换旧的。Hyperliquid 建议注销过的地址不要再用，所以每次批准请用 keygen 新生成的闸门密钥。

    主网：批准后这把密钥可以用你账户里的真钱下单。只在你已经用测试网跑过、并签好授权文件之后再做。

    3 · 撤销授权

    先在运行闸门的机器上执行 agent-gate mandate revoke-text --config gate.json，把它打印的两行原文粘到下面，用签授权时的同一个钱包签名，再把签名交给 agent-gate mandate revoke-attach --sig …。从那以后闸门拒绝这份授权下的所有订单，撤销本身也记进账本。

    没有检测到钱包？需要 MetaMask、Rabby 之类的浏览器钱包。测试网要先领测试 USDC：app.hyperliquid-testnet.xyz/drip（Hyperliquid 要求这个地址在主网入过金）。
