Agent gate · open source, MIT

Your AI agent can trade. Only inside limits you signed.

The agent sends orders to the gate, not the broker. The gate passes what fits your limits, refuses the rest, and signs every decision into a ledger that anyone can audit without trusting the gate.

How it works

Three steps, and the agent never holds a key that can trade.

01
Sign the limits

Symbols, largest order, per-symbol position, daily loss, orders a day, expiry. You sign them with your own Ethereum wallet; the document names the one key allowed to act: the gate's.

agent-gate keygen .gate/gate.key
agent-gate mandate draft --config gate.json \
    --issuer 0xYourWallet --days 14
# sign the printed text in your wallet
agent-gate mandate attach --sig 0x…
02
The agent asks the gate

Over MCP, or through an adapter in its own framework. Orders inside the limits go to the broker; the rest are refused, with the reason. An order that only reduces risk always passes.

place_order("ETH", "buy", usd=5000)
→ {"decision": "block",
   "reasons": ["order is $5,000.00, above
               the $500 single-order limit"]}
03
Audit from the ledger alone

Each line carries the hash of the one before and the gate's signature. audit re-checks every allowed order against the signed limits. A wholesale rewrite of the file, which a bare hash chain cannot catch, is caught.

agent-gate audit --config gate.json
→ {"ok": true, "mandates": 1,
   "orders_allowed": 2, "orders_rechecked": 2,
   "problems": []}

The agent's reply (excerpt, translated)

BTC was bought. The ETH order was refused by the gate and did not fill.

I did not split the $5,000 into ten orders of $500 to get round the limit. A refusal from the gate is final; splitting the order would defeat the risk rule you set.

If $5,000 is the position you really want, raise max_order_usd in the gate's config. That is for you to change, not me.

What we found

A daily-loss limit alone does not cap a day.

We replayed the gate's own rules on 199 real days of Hyperliquid hourly returns (BTC, ETH), 30 days × 1,000 runs, starting at $10,000, $500 an order, 20 orders a day. The limit stops new risk, not losses on what is already held. So the default rules now include a per-symbol position limit.

Install

Three minutes, from a clone.

git clone https://github.com/Beltran12138/evidence-deflator && cd evidence-deflator
pip install mcp eth-account
python src/agent_gate.py demo                 # a scripted agent: allowed, refused, a tampered ledger caught
python src/agent_gate.py init gate.json       # default limits, then edit
python src/gate_stress.py --config gate.json  # what these limits allow, on real returns
python src/gate_server.py --config gate.json  # the gate as an MCP server for your agent

Sign a mandate with your wallet: /gate/sign/. Spec: MANDATE.md. Adapters: INTEGRATIONS.md.

The scorecard

Is your agent's record skill, or luck?

The ledger's equity is scored with the same ruler as our wallet check: weekly returns, a t-statistic, and a bar that rises with how many candidates were tried. Of Hyperliquid's all-time top 100 by profit, none clears it yet.
