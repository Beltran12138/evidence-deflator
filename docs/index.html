Why does no one clear it? Can it ever say yes?

Zero is what a board with no proven skill looks like. If none of the 47,440 accounts had any skill, luck would carry anyone at all past 4.90 only about 2% of the time: that is how the bar is set.

It can say yes; the records are short. The chance that a trader whose true Sharpe is S clears 4.90 after a given length of record:

The median record in this top 100 is 1.7 years. If every one of these 99 had a true Sharpe of 3, about 22 would clear the bar by now, given their record lengths. 0 do.

How high the bar sits also depends on how independent the accounts are: 4.90 if each is a separate bet, about 2.6 by our rough estimate if many trade alike (3 clear that). Can it say yes · how the bar is set.
