托管接口、MCP 与 Python

查 Hyperliquid 钱包不用安装任何东西；检验回测的引擎是纯 Python 标准库，不要密钥、不联网、不执行代码。

托管：通过 HTTP 和 MCP 检验钱包

托管接口读取钱包的公开历史并打分，用的是和钱包页面在你浏览器里跑的同一套代码。

curl "https://api.evidencedeflator.com/api/wallet?a=0xADDRESS&picked_from=47153"

picked_from 是你从多大的榜单里挑出这个钱包；不传就按「没经过筛选」处理，门槛是 2。

远程 MCP（Streamable HTTP，免密钥）：在 Claude、ChatGPT、Cursor 或任何 MCP 客户端里，把 https://api.evidencedeflator.com/mcp 添加为连接器。它只有一个只读工具 hyperliquid_wallet(address, picked_from)。在 Claude Code 里：

claude mcp add --transport http evidence-deflator https://api.evidencedeflator.com/mcp

或者安装 Claude Code 插件。它带同一个工具、一个告诉 agent 如何汇报结论的 skill，以及一个给每次回测计数的 hook：

/plugin marketplace add Beltran12138/evidence-deflator
/plugin install evidence-deflator@evidence-deflator

Python

Python ≥ 3.8 · MIT
from evidence_deflator import effective_window, selection_penalty, months_for_power

w = effective_window(cutoff="2024-10", start="2020-01", end="2025-06", trials=41)
w.open_book_months   # 58  截止日当月及之前的月份
w.effective_months   # 8   干净月份
w.months_required    # 128 夏普 1、41 选 1 时需要的干净月份
w.verdict            # 'underpowered'（检验力不足）
w.to_dict()          # 全部结果，附文字推理

selection_penalty(41).t_adjusted   # 3.26
months_for_power(2.0)               # 12

用 cutoff_source= 传入模型提供方的文档链接；不传的话，结果会注明截止日未经核实。测得了尝试之间的相关程度时，传 effective_trials=。

命令行

git clone https://github.com/Beltran12138/evidence-deflator
cd evidence-deflator
python tools/window.py --cutoff 2024-10 --start 2020-01 --end 2025-06
python tools/record.py --start 2026-03 --end 2026-08 --sharpe 3 --trials 4800

本地 MCP 服务器

适用于 Claude、Cursor 等 MCP 客户端，工具包括 knowledge_window、track_record、counterfactual_audit、trace_audit 和 hyperliquid_wallet。

pip install "evidence-deflator[mcp]"

{
  "mcpServers": {
    "evidence-deflator": { "command": "evidence-deflator-mcp" }
  }
}
