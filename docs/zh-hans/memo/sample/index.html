Hyperliquidity Provider（HLP）

金库 0xdfc24b077bc1425ad1dea75bcb6f8158e10df303 · 数据来自 api.hyperliquid.xyz，读取于 2026-10-16 10:18:45 UTC · 原始数字

问题 一位存款人在看 HLP，因为它是 Hyperliquid 全期 PnL 榜上最强的记录。这份记录里有多少算得上证据？ 简短回答有希望，未证实 如果是随手挑中的，这个强度够了：179 周记录，t = 3.43。但它是从 47,310 个账户里挑出来的第一名，门槛是 4.90，还不够；按它自己 1.91 的夏普比率，大约还要 38 个月。而且它反映的不是某个交易员的本事：这是交易所自己的金库，收入来自做市、清算和平台手续费。

一、这份记录是什么

  • Hyperliquid 上的一个金库，Hyperliquid 的官方描述是：“This community-owned vault provides liquidity to Hyperliquid through multiple market making strategies, performs liquidations, and accrues platform fees.” 目前开放存款。管理人自己持有 0.20%，从存款人的盈利里抽 0%。
  • 它下面有 7 个子金库，其中 3 个也在全期 PnL 前 100 名里（#23 HLP Liquidator、#59 HLP Strategy A、#82 HLP Strategy B），所以那张榜把同一个业务算了 4 次。
  • 历史从 2023-05-10 到 2026-10-16：98 个计分区间，共 179.2 周。Hyperliquid 历史里没有新数据点的周，并入下一个区间，不记为零收益。
  • 覆盖范围：HLP 在 HyperCore 上交易，全部盈亏都在 Hyperliquid 记录里；钱包页提到的 HyperEVM 缺口对它不适用。充值和提现只改变账户价值，不改变盈亏。

二、数字

指标数值解读
t（Student t，有效自由度 93）3.43年化夏普 1.91 × √3.4 年，已按记录长度校正
随手挑中时的门槛2.00过
47,310 选 1 的门槛（账户视为相互独立）4.90没过；按当前夏普大约还要 38 个月
同一门槛，粗略考虑交易方式相近的账户≈ 2.6过；这是数量级，不是测量值

三、t 看不到什么

  • 记录的形状。89% 的区间是正收益。最差的三个区间分别是 -4.4%、-4.2%、-4.0%；按区间复利计算，最深回撤 5.8%。偏度 +4.9：最大的波动是盈利。至少到目前为止，这不是「赚小钱、亏大钱」的形状。
  • 还没发生的尾部。接手被清算仓位的金库，在价格跳空时站在对手方。它可能遭遇的最坏情况，不一定出现在这 3.4 年的历史里，t 也无法给它定价。
  • 收益从哪里来。手续费和清算收入来自交易所自身的业务。对存款人来说，问题与其说是有没有人有本事，不如说是这笔收入能不能持续、条件是什么。

四、什么会改变结论

  • 更长的记录：夏普保持 1.91 不变的话，大约再过 38 个月能过 47,310 选 1 的门槛。
  • 前向记录：HLP 是 2026-10-14 冻结的 200 个钱包之一。冻结之后的记录从 2026-12-09 起每天公布分数。
  • 一次明显深于目前 5.8% 的回撤，那会暴露上面说的尾部风险。

五、方法与复现

和钱包检验用的是同一个估计方法，定义见方法页。复现：在仓库里运行 python tools/memo_sample.py 0xdfc24b077bc1425ad1dea75bcb6f8158e10df303 out.json --board-n 47310。

本页用一份公开记录展示一页证据评估报告的格式，不构成投资建议。HLP 没有参与，也没有付费；我们从不收被评估一方的钱。想为你正在考虑的地址要一份？在 GitHub 上提出。
