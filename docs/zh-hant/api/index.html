託管接口、MCP 與 Python

查 Hyperliquid 錢包不用安裝任何東西；檢驗回測的引擎是純 Python 標準庫，不要密鑰、不聯網、不執行代碼。

託管：通過 HTTP 和 MCP 檢驗錢包

託管接口讀取錢包的公開歷史並評分，用的是和錢包頁面在你瀏覽器裏跑的同一套代碼。

curl "https://api.evidencedeflator.com/api/wallet?a=0xADDRESS&picked_from=47153"

picked_from 是你從多大的榜單裏挑出這個錢包；不傳就按「沒經過篩選」處理，門檻是 2。

遠程 MCP（Streamable HTTP，免密鑰）：在 Claude、ChatGPT、Cursor 或任何 MCP 客戶端裏，把 https://api.evidencedeflator.com/mcp 添加為連接器。它只有一個只讀工具 hyperliquid_wallet(address, picked_from)。在 Claude Code 裏：

claude mcp add --transport http evidence-deflator https://api.evidencedeflator.com/mcp

或者安裝 Claude Code 插件。它帶同一個工具、一個告訴 agent 如何彙報結論的 skill，以及一個給每次回測計數的 hook：

/plugin marketplace add Beltran12138/evidence-deflator
/plugin install evidence-deflator@evidence-deflator

Python

Python ≥ 3.8 · MIT
from evidence_deflator import effective_window, selection_penalty, months_for_power

w = effective_window(cutoff="2024-10", start="2020-01", end="2025-06", trials=41)
w.open_book_months   # 58  截止日當月及之前的月份
w.effective_months   # 8   乾淨月份
w.months_required    # 128 夏普 1、41 選 1 時需要的乾淨月份
w.verdict            # 'underpowered'（檢驗力不足）
w.to_dict()          # 全部結果，附文字推理

selection_penalty(41).t_adjusted   # 3.26
months_for_power(2.0)               # 12

用 cutoff_source= 傳入模型提供方的文檔連結；不傳的話，結果會註明截止日未經核實。測得了嘗試之間的相關程度時，傳 effective_trials=。

命令行

git clone https://github.com/Beltran12138/evidence-deflator
cd evidence-deflator
python tools/window.py --cutoff 2024-10 --start 2020-01 --end 2025-06
python tools/record.py --start 2026-03 --end 2026-08 --sharpe 3 --trials 4800

本地 MCP 服務器

適用於 Claude、Cursor 等 MCP 客戶端，工具包括 knowledge_window、track_record、counterfactual_audit、trace_audit 和 hyperliquid_wallet。

pip install "evidence-deflator[mcp]"

{
  "mcpServers": {
    "evidence-deflator": { "command": "evidence-deflator-mcp" }
  }
}

數據
